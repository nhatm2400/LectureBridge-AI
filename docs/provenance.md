# Provenance and Third-Party Software

LectureBridge application code, synthetic evaluation transcripts, draft annotations, review templates, demo generator, application icon, and CSS-based product visuals in this repository are project-authored.

The public frontend bundles one project-authored SVG application icon. Other product visuals use CSS and icons from the installed Lucide React package. No stock illustration, third-party lecture recording, unused binary template, or unresolved-provenance media is bundled.

Runtime course thumbnails and lecture media are user-provided private data. They require their own permission and provenance review before separate publication.

Core third-party software includes FastAPI, SQLModel, Alembic, faster-whisper, FFmpeg tooling, the OpenAI Python client, PostgreSQL drivers, Redis/RQ, boto3, Next.js, React, Tailwind CSS, Zustand, Framer Motion, and Lucide React. Each remains governed by its upstream license.
