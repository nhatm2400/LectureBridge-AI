# Submission description — English

**Project name:** LectureBridge AI

**Description (maximum 150 words):**

Captions show the words; LectureBridge restores the learning thread. When a learner misses part of a lecture, a long transcript still may not reveal what changed, which question was answered, or why the current topic matters. LectureBridge maps timestamped Vietnamese, English, and code-switch transcripts into a Semantic Timeline of topic changes, questions, linked answers, examples, and important moments. Context Recovery reconstructs the recent learning path, and each item returns the learner to backend-validated source evidence in the protected video. Grounded Ask answers only from the current lecture and abstains when evidence is insufficient. This evidence-grounded learning-continuity approach supports text-first learners, including Deaf and Hard-of-Hearing students, without claiming one universal accessibility experience. In a small synthetic human-verified evaluation, Event precision was 20/20, VI/EN full-recall Event recall was 11/12, Q↔A linking was 3/3, Context grounding was 51/51, and unsupported-question abstention was 5/5.
